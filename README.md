# MountPilot · 远程挂载助手

通过中文交互菜单，在 Linux 服务器上配置 FTP / FTPS / SFTP，并使用 **rclone + FUSE + systemd** 持续挂载为本地目录。

适合希望少写命令、按提示配置远程存储的用户。默认关闭磁盘文件缓存，支持开机挂载、状态检查、日志查看、密码修改及卸载。

> 当前收录 V3 实验版本，保留原始实现。已做语法与部分逻辑检查，尚未完成真实 Linux 环境的完整集成测试。已知限制见本文末尾；请先使用测试账号和少量文件验证。

## 功能

- 中文交互：输入协议、主机、端口、账号、密码、远程目录和本地挂载目录。
- 检查依赖，确认后从系统软件源安装所需工具。
- 支持 FTP、显式 FTPS、隐式 FTPS、SFTP。
- SFTP 支持密码或私钥认证，并显示主机公钥指纹供用户核对。
- FTPS 支持系统证书验证、自签名证书导入及显式选择跳过验证。
- 默认不使用本地磁盘文件缓存，可选写入缓存。
- systemd 常驻，可选开机启动；进程异常退出后尝试重启。
- 查看挂载状态、测试远程连接、查看日志、修改密码、卸载和删除配置。
- 尝试通过目录权限及 `chattr +i` 降低挂载断开后误写本地磁盘的风险。

## 支持范围

| 项目 | 当前支持情况 |
| --- | --- |
| Ubuntu / Debian | 支持自动安装依赖，需 systemd |
| RHEL / Rocky / Alma 等 dnf 系统 | 支持安装流程；rclone 可能需要先启用 EPEL 或自行安装 |
| Python | 3.7 或以上 |
| rclone | 脚本要求 1.60 或以上，建议使用经过验证的官方稳定版 |
| 权限 | 必须 root；普通用户使用 sudo |
| 运行环境 | 必须有交互终端、systemd 和 `/dev/fuse` |
| OpenWrt / macOS / Windows | 不支持运行本脚本 |
| 普通 Docker 容器 | 不支持作为常规部署方式 |
| OneDrive / Google Drive / S3 / R2 / WebDAV | 当前交互向导不支持 |

rclone 支持很多后端，但本脚本目前只生成 `ftp`、`sftp` 配置，不等同于支持 rclone 的所有平台。

## 快速开始

从本仓库下载 `remote-mount-v3.sh`，上传到服务器，然后运行：

```bash
sudo bash remote-mount-v3.sh
```

如果本来就是 root：

```bash
bash remote-mount-v3.sh
```

首次选择 `1 新增并挂载`，按提示填写。建议使用 `/mnt/myftp` 这样的新目录。

再次运行同一命令，即可管理已有连接。脚本不需要复制到固定位置，但不要手动移动它保存的配置文件。

依赖缺失时会询问是否安装。软件源或网络不可用时，请先解决安装问题。自动安装可能运行 `apt-get update`，并安装 rclone、fuse3、util-linux、e2fsprogs；SFTP 还需要 OpenSSH 客户端工具。Python 缺失时会先询问安装 Python。自签名证书获取需要额外具备 `openssl` 和系统证书更新工具。

脚本不会自动升级已安装的 rclone；若软件源版本低于脚本要求，需要自行安装合适版本。

## 菜单

| 编号 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 新增并挂载 | 新建独立连接和 systemd 服务 |
| 2 | 状态 | 查看服务、挂载类型、目录响应、缓存占用；可选远程连接测试 |
| 3 | 重启挂载 | 普通卸载后重新启动；可询问启用开机挂载 |
| 4 | 卸载并取消开机挂载 | 保留账号配置，下次可以重新挂载 |
| 5 | 查看日志 | 显示最近 60 条服务日志 |
| 6 | 修改登录密码 / 私钥口令 | 测试新凭据后保存，可选重启生效 |
| 7 | 删除连接配置 | 停止服务、取消开机挂载并删除配置、私钥副本、缓存及导入的证书 |
| 8 | 强制修复失效挂载 | 强制断开挂载，可选重新启动；正在读写的任务可能失败 |
| 0 | 退出 | 只退出菜单，不停止正在运行的挂载 |

## 配置项详解

### 连接与路径

| 配置项 | 默认值 / 可选值 | 填写说明 |
| --- | --- | --- |
| 连接名称 | 无默认值 | 小写字母开头，只能含小写字母、数字和短横线，最长 31 字符；不能与已有配置或服务重名 |
| 协议 | 显式 FTPS | 1 FTP、2 显式 FTPS、3 隐式 FTPS、4 SFTP |
| 主机 | 无默认值 | IP 或域名，不带协议、路径、端口；IPv6 不加方括号 |
| 端口 | FTP/显式 FTPS：21；隐式 FTPS：990；SFTP：22 | 可自定义为 1～65535；端口不能用于判断协议，最终以提供方说明为准 |
| 登录账号 | 无默认值 | 远程服务器账号，不能为空 |
| 登录密码 | 无默认值 | 隐藏输入，需输入两次；当前密码登录不接受空密码 |
| 远程目录 | 留空 | 留空使用账号默认目录；以 `/` 开头和相对路径可能含义不同，按远程账号实际可见路径填写 |
| 本地挂载目录 | `/mnt/连接名称` | 必须是空目录或不存在的绝对路径；不能与已有连接路径重叠 |
| 本地访问用户 | 留空，仅 root | 可输入已存在的 Linux 用户名，允许该用户及 root 使用；不创建系统用户 |
| 开机自动挂载 | 默认否 | 输入 y 启用；否则仅本次启动，退出菜单不影响当前挂载 |

本地路径不支持空格、引号、反引号、反斜杠、`%`、`$` 等字符。脚本拒绝直接挂到根目录或一级目录，并限制 `/proc`、`/sys`、`/dev`、`/run`、`/boot`、`/etc`、`/usr`、`/bin`、`/sbin`、`/lib`、`/lib32`、`/lib64`、`/libx32`、`/var/lib`、`/var/cache`、`/var/log`、`/tmp`、`/var/tmp` 及其子目录。路径会解析符号链接后再检查。

授权普通用户时，脚本设置 `--allow-other --default-permissions --uid ... --gid ... --umask 077`。父目录也必须允许该用户进入，例如 `/root` 通常不允许普通用户进入，因此推荐使用 `/mnt`。

### FTP / FTPS 专用选项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 最大连接数 | 0，不限制 | 范围 0～64。只有服务商有明确限制时才调整；设置过小可能导致等待甚至死锁 |
| 旧服务器兼容 | 关闭 | 开启后禁用 EPSV、MLSD；不能替代服务端放行被动模式端口 |
| FTPS 证书验证 | 使用系统信任证书 | 保留服务器身份校验及主机名校验 |
| 自签名证书导入 | 手动选择 | 获取服务器证书，显示 SHA256 指纹及相关信息；确认后加入系统证书库 |
| 跳过证书验证 | 关闭 | 必须明确确认，失去服务器身份验证，不建议在公网使用 |

普通 FTP 会明文传输账号、密码和数据。FTPS 是 FTP 加 TLS，SFTP 是基于 SSH 的另一种协议，两者不能混用。

自签名证书必须与服务商通过可信渠道提供的指纹核对；仅看到脚本显示指纹，不代表服务器身份已经可信。证书中的 SAN 需匹配填写的域名或 IP。导入会影响整台服务器的信任范围，不只是本连接。

### SFTP 专用选项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 认证方式 | 密码 | 可选择私钥认证 |
| 私钥文件 | 无 | 输入本机已有私钥的绝对路径，脚本会复制到自己的配置目录；不会生成密钥或把公钥安装到远程 |
| 私钥口令 | 可留空 | 仅用于加密私钥，与账号密码不同 |
| 主机公钥指纹 | 必须确认 | 使用 ssh-keyscan 获取并通过 ssh-keygen 显示，与提供方核对后保存到独立 known_hosts 文件 |

主机密钥变更会导致验证失败，应先核实远程是否重装或更换密钥，不要盲目绕过验证。

### 缓存选项

| 模式 / 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 模式 1：不落盘 | 默认 | `--vfs-cache-mode off`，不使用 VFS 磁盘文件缓存；仍会使用内存、日志及配置空间 |
| 模式 2：写入缓存 | 可选 | `writes`，写入先落本地磁盘，文件关闭后后台上传 |
| 缓存清理目标 | 5G | 接受整数 M/G，如 500M、5G；不是硬性上限 |
| 缓存保留时间 | 固定 24h | `--vfs-cache-max-age 24h`，符合条件的闲置缓存可清理，不是上传超时 |
| 尽量保留空闲空间 | 2G | 当前 rclone 支持该参数时才提供，同样不是硬性保证 |
| 缓存目录 | `/var/cache/remote-mount-helper/连接名称` | 每个连接独立；创建时拒绝复用已有同名缓存目录 |

**正在打开或还未上传完成的文件不会因为达到清理目标就被安全删除。大文件、低上传速度或上传失败仍可能占满磁盘。**

`off` 适合普通顺序复制，但不支持所有随机写入、追加、原地修改等操作。它不是数据库或通用本地硬盘的替代品。写缓存模式中，`cp` 返回成功不代表远程上传已经完成。重启后可尝试从保留的缓存继续上传，但不保证源文件级断点续传。

## 固定运行参数与文件位置

这些不是当前向导中可直接修改的选项：

| 项目 | 值 / 行为 |
| --- | --- |
| 配置目录 | `/etc/remote-mount-helper`，仅 root 可访问 |
| rclone 配置 | `连接名称.conf`，与原有 `~/.config/rclone/rclone.conf` 分开 |
| 管理元数据 | `连接名称.json` |
| SFTP 主机密钥 | `连接名称.known_hosts` |
| 私钥副本 | `连接名称.key` |
| systemd 服务 | `/etc/systemd/system/remote-mount-连接名称.service` |
| 退出清理脚本 | `/etc/remote-mount-helper/stale-cleanup.sh` |
| 自签名证书 | Debian 系 `/usr/local/share/ca-certificates/remote-mount-连接名称.crt`；RHEL 系对应系统证书目录 |
| 日志 | systemd journal，不另建独立日志文件；占用及保留策略由系统管理 |
| 目录列表缓存 | 30 秒；远程其他客户端的修改可能不会立即显示 |
| 默认权限掩码 | `077` |
| systemd 服务类型 | `notify`，以前台方式运行 rclone |
| 自动重启 | 进程失败后等待 15 秒重启；网络故障不一定导致进程退出 |
| 启动超时 | 90 秒 |
| 停止超时 | 无磁盘缓存 30 秒；写入缓存 300 秒 |
| 网络顺序 | 在 network-online.target 后启动，不保证远程服务可达 |
| 连接测试 | lsf，连接超时 10 秒、I/O 超时 20 秒、重试各 1，外层最长约 60 秒 |
| 目录响应检查 | 20 秒，超时后尝试结束并回收检查进程 |

配置中的密码是可逆混淆，不是强加密。不要公开 `.conf`、`.key`、Token、数据库备份或包含敏感内容的日志。

## 使用示例

假设连接名 `myftp`，挂载目录 `/mnt/myftp`：

```bash
# 每次复制前先确认挂载，防止误写本地磁盘
mountpoint /mnt/myftp

# 只有确认仍挂载才开始复制
mountpoint -q /mnt/myftp && cp -v /path/to/file.zip /mnt/myftp/

# 查看服务和日志
systemctl status remote-mount-myftp.service
journalctl -u remote-mount-myftp.service -n 60 --no-pager
```

`mountpoint` 只证明存在挂载，不证明它属于预期远程、联网正常或后续永不掉线。

如果目的是大量文件迁移，通常直接执行 rclone copy 更便于重试和记录进度，不必经过挂载：

```bash
rclone copy /path/to/source myftp:backup \
  --config /etc/remote-mount-helper/myftp.conf \
  --transfers 2 --checkers 2 --progress
```

这里的远程路径需按实际填写；若服务商限制连接数，还需按 rclone 文档调整并发。`copy` 不删除源文件或远程额外文件，但可覆盖远程同名不同内容的文件。`sync` 会删除远程多余文件，请勿混用。使用 tmux/systemd 可避免终端关闭中断复制；挂载服务本身不会自动执行同步任务。

## 卸载与移除

再次运行脚本，选择菜单 4：卸载并取消开机挂载，保留连接配置。

选择菜单 7：删除连接及相关管理文件；存在缓存数据时会额外提示。删除后未上传的数据无法由脚本恢复。远程文件不属于脚本的清理目标。

脚本不会卸载系统的 rclone、FUSE、Python 等共享依赖，也不会删除用户原始私钥。新建的空挂载目录会尝试删除，原有空目录会尝试恢复权限；失败时需人工处理。不要在挂载仍存在时递归删除挂载目录。

## 常见问题

### 登录端口能连，列目录却超时

FTP 登录连接和数据连接使用不同端口。服务商需放通被动数据端口范围，并正确配置公网地址及 NAT；IP 白名单也需覆盖对应规则。本机出站防火墙同样可能拦截数据连接。

### 为什么文件仍占本地空间？

可能使用了写入缓存、保留了本地源文件，或者挂载断开后程序写入了普通本地目录。先检查挂载、缓存、源文件及磁盘占用，不要直接清空缓存：可能含未上传的唯一副本。

### 为什么别的用户或 Docker 容器看不到？

检查向导中的本地授权用户和父目录权限。Docker 需要正确 bind mount；应在挂载成功后启动容器，或由了解 Linux 挂载传播的管理员配置传播。不要把 `rshared` 当作无条件通用修复。

### 目录能列出来，是否代表远程正常？

不一定，目录列表可能命中缓存。菜单 2 可单独测试远程连接；即使测试成功，也不能保证后续读写持续可用。

### 断网会自动恢复吗？

systemd 对进程失败进行重启，rclone 也有自身网络处理逻辑；不能保证每种断网都能自动恢复。先看日志，普通卸载失败时排查占用，仅在确认后使用强制修复。

## 当前已知限制

当前源码保留 V3 原状，以下项目尚未修复：

1. **服务停止失败未充分检查。** `release()` 可能在 systemctl 停止/禁用失败时仍返回成功；删除流程可能继续删除配置或缓存。删除前务必自行确认服务 inactive、挂载消失，并核实缓存是否仍有待上传数据。
2. **挂载归属识别不充分。** 普通卸载、强制修复及退出清理主要按路径和 `fuse.rclone` 类型判断，不能严格区分同一路径上的其他 rclone 实例。请专用挂载目录，不要手动叠加或替换挂载。
3. **残留配置清理存在相同停止确认不足。** 启动时发现残留配置，确认清理前需检查是否仍有关联服务、挂载或数据。
4. **自签名证书信任是系统级。** 并非仅本连接信任该证书；导入前核对指纹和范围。
5. **依赖版本检查不是完整能力检测。** 达到最低版本不表示所有发行版补丁和选项组合均已验证。正式使用前实测所需功能。
6. **不是数据完整性验证器或全自动备份系统。** 不提供同步计划、上传完成的强校验、版本保留、恢复保证或网盘 OAuth 向导。
7. 可能遗留共享辅助脚本、空目录或软件包；不承诺对中断、突然断电和手动修改状态完全回滚。
